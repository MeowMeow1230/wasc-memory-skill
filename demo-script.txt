# Nest Demo 旁白稿

## 指令

python3 scripts/demo.py


## Act 1：煩躁 — AI 每次都像第一次見你

大多數 AI Skill 有一個共同的問題：每次對話都像第一次見你。

你糾正過的事，換一個檔案、換一個專案、甚至同一場對話的後面，它又忘了。

Nest 就是為了解決這個問題。它是 WASC 六月挑戰「自成長·越用越懂你」的提交作品。

評審現在看到的是清空記憶的狀態。零條偏好，從零開始。

用戶請 AI 寫一個計算總價的 Python 函數。AI 輸出了 camelCase 命名，充滿多餘的註解。

Nest 在後台觀察。不打擾。只記錄。

用戶糾正了。不只是糾正——用戶說「不要用 camelCase，用 snake_case，註解太多，加 type hints」。

Nest 的雙軌信號捕獲啟動了。第一軌，regex 偵測到「不要」這個否定關鍵詞。第二軌，Claude Code 自己判斷這句話的語氣——這不是建議，這是紅線指令。立即標記，立即準備學習。

重點是：Nest 不只聽你說什麼。它更看你改什麼。如果你嘴上說 OK，手上卻把程式碼整段重寫——Nest 學的是你做了什麼，不是你說了什麼。行為比話語更誠實。


## Act 2：懷疑 — 它真的學得會嗎？

紅線觸發後，Nest 不等待第三次犯錯。立即啟動分類。

注意：Nest 沒有呼叫任何外部 API。分類引擎就是 Claude Code 自己。Claude Code 讀取原始信號，用自己的智慧理解語義，提取出結構化記憶。

現在評審可以看到三條記憶。每一條都有完整的結構：它是什麼類型的偏好、適用什麼範圍、觸發條件是什麼、以及背後的抽象原則。

跟其他參賽作品最大的不同：每條記憶都帶有 source_signals。評審可以精確追溯到這條記憶是從哪一輪對話學來的。不是黑箱。完全透明。

記住：我們只展示機制，不展示概念。所有輸出都是可觀察、可驗證的。


## Act 3：Aha Moment — 越用越安靜，越用越合身

這是 Nest 的核心價值。

用戶確認偏好後，規則升級到 RULE 級別。從這一刻開始，Nest 永遠沉默。不問問題、不彈確認、不顯示任何東西。

但沉默不等於消失。注意螢幕上出現了一行 PS：「新規則已成熟」。這是 Nest 的學習脈搏——只在規則成熟時輕量提示一句，讓你知道 Skill 活著、在成長、在生效。不煩人。就一句。

新任務：寫 TypeScript 函數。Nest 自動從記憶庫選出最相關的三條規則，注入到當前任務的上下文。AI 輸出蛇形命名、無註解、有類型標註。

用戶沒有說一句話。Python 的偏好泛化到了 TypeScript。這就是自成長。

然後偏好變化了。用戶說公開 API 可以加 JSDoc。Nest 不把這當成衝突——它理解這是範圍的差異。全局規則不變，特定目錄加例外。情境感知：同一個專案，internal 目錄沒有註解，public-api 目錄有 JSDoc。不同場景，不同規則，互不污染。

最後，刪除後復測。評審要求刪除 snake_case 這條規則。Nest 立即停止使用。記憶刪除，即時生效。

Claude Code 中所有操作都可以用 /memory 命令直接完成。查看、編輯、刪除、重置。不需要跳出對話。不需要管理界面。


## 結尾

最後一行顯示的是 Nest 的新會話脈搏：「歡迎回來。上次學到三條偏好，三條已自動套用」。每次你打開新會話，Nest 會用一句話告訴你它記得什麼。讓你知道 Skill 不是黑箱，是活著的。

三條規則從零開始學到。用戶糾錯次數從五次降到零次。Rubric 評分：一百分。

但真正的分數不在這裡。真正的分數在於——用戶不再需要重複說話。

Nest。你的偏好，越用越合身。
