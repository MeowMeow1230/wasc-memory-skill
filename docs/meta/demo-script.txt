# Nest Demo 旁白稿（口語版）

## 指令

python3 scripts/demo.py


## Act 1：煩躁

大多數 AI Skill 有個問題。每次對話都像第一次見你。

你糾正過的事。換個檔案就忘了。同一個對話後面也忘了。

Nest 解決這個問題。WASC 六月挑戰。主題是自成長、越用越懂你。

現在看評審視角。清空記憶。零條偏好。從頭開始。

用戶叫 AI 寫 Python。AI 輸出 camelCase。還有一堆註解。

Nest 在後台看著。不打擾。只記錄。

用戶糾正了。不要 camelCase。用 snake_case。註解太多。加 type hints。

Nest 雙軌捕獲啟動。第一軌，regex 抓到否定詞。第二軌，Claude Code 判斷語氣是紅線。

重點。Nest 不只聽你說話。更看你改什麼程式碼。你說 OK，但把程式碼整段重寫了。Nest 知道你其實不滿意。行為比話語誠實。


## Act 2：懷疑

紅線一觸發。立刻分類。不等第三次犯錯。

注意。Nest 沒有外部 API。分類引擎就是 Claude Code 自己。

現在看到三條記憶。每條都有完整結構。什麼類型。什麼範圍。什麼條件。背後的原則。

跟別人不一樣的地方。每條記憶可以追溯來源。哪一輪對話學到的。不是黑箱。完全透明。


## Act 3：Aha Moment

用戶確認。規則升到 RULE。從此沉默。

但沉默不是消失。你看螢幕跳出一行 PS。新規則已成熟。這是學習脈搏。一句話。讓你知道 Skill 活著、在成長。

現在新任務。寫 TypeScript。Nest 注入三條相關規則。AI 輸出蛇形命名。無註解。有類型標註。

用戶一句話都沒說。Python 偏好泛化到 TypeScript。這就是自成長。

偏好變化了。公開 API 可以加 JSDoc。Nest 不當衝突。這是範圍差異。全局規則不變。特定目錄加例外。

看情境感知。internal 目錄無註解。public-api 目錄有 JSDoc。不同場景。不同規則。互不污染。

刪除後復測。刪掉 snake_case 規則。立刻停止使用。即時生效。

所有操作 Claude Code 直接用 /memory。查看、編輯、刪除、重置。不用跳出對話。不用管理界面。


## 結尾

最後一行。新會話脈搏。歡迎回來。學到三條偏好。已自動套用。

三條規則。從零開始學。糾錯從五次降到零次。Rubric 一百分。

真正的分數不在這裡。在於不用再重複說話。

Nest。你的偏好。越用越合身。
