· 一句话简介：一个从对话纠错和代码修改行为中自动学习偏好，然后沉默应用的 Claude Code Skill——不靠外部 API，Claude Code 自己就是分类引擎。

· 亮点说明：
  1. 双轨信号捕获——不只监听用户说什么，更观察用户改了什么代码（Diff 分析）
  2. 零外部 API——所有语义理解由 Claude Code 原生完成，不呼叫任何第三方 LLM
  3. JIT 情境注入——按项目/目录 scope 精准匹配，每次只注入最相关的 Top 20 条记忆
  4. 学习脉搏——定期轻量状态提示，用户知道 Skill 活着但不被打扰
  5. 完整追溯——每条记忆带 source_signals，可精确追溯到哪个对话产生的
  6. 真实场景验证——在 108 个真实 Claude Code 历史 session 上交叉验证信号捕获一致性

· 适用场景：AI 辅助编程、多项目协作、任何需要长期记忆和自适应偏好的 AI 编码场景
