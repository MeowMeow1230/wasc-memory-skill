🚀 Just open-sourced a little thing: Nest 🪺

If you, like me, use Claude Code for coding,
you've probably had this moment: "Didn't I tell you last time — no camelCase?"
"No comments, how many times do I have to say it?"
"Discuss first, then code. You just jumped in again."

Every session switch, every project switch — same preferences, repeated 5-8 times.
Eventually you just stop correcting and fix it yourself.

Nest solves this as a Claude Code Skill:

🪺 Dual-track signals — learns from what you say AND what you edit.
   You say "OK" but rewrite the whole thing? Nest knows you weren't happy.
🔥 Red-line intercept — you say "absolutely don't", it learns immediately. No waiting.
🧠 Zero external API — Claude Code IS the classification engine. No third-party LLM calls.
💓 Learning pulse — a one-line ping when a rule matures. You know it's alive, not annoying.
📂 Project isolation — Manbang preferences don't leak into CrunchDAO.
📊 Quantified — cross-validated on 108 real Claude Code history sessions.
🎯 Rubric 100/100 — full WASC 6-dimension scoring.

Pure stdlib, zero pip dependencies. MIT-0 — use it, fork it, ship it.

Meta part: the whole thing (design docs, test harness, bilingual README)
was basically built with Claude Code itself 😄
